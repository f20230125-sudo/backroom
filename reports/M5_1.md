# M5.1: shadcn/ui and readable results

Implemented on 27 October 2026. The UI uses the installed shadcn components and Tailwind v4 theme. No packages were added, no network or recording commands were used, and the protected extraction, model, Ask and name engines and data artifacts were not edited.

## What changed

- `web/src/main.tsx`, `App.tsx`, `index.css`: import the shadcn theme, remove `style.css`, use a desktop sidebar and wrapping phone navigation, preserve the skip link and current-page navigation, and apply the HTML `dark` class with system preference and guarded local storage.
- `web/src/components.tsx`: shared Cards, Tables, status Badges, labelled filters, Collapsible evidence, loading Skeletons, source highlighting, and exact integer-based hours calculations with Inputs and Labels.
- `web/src/components/ui/badge.tsx`, `table.tsx`, `select.tsx`: accessible amber and accepted/reconciled variants; stronger destructive-token contrast; keyboard-scrollable tables; and a CSP-compatible select composed from the installed Button and Collapsible primitives.
- `web/src/format.ts`: a shared machine-code vocabulary, Dubai dates/times, one-decimal percentages with denominators, and decimal-string money formatting. Invoice VAT percentage points are distinguished from fractional evaluation rates; emirate codes remain text.
- `web/src/pages/Overview.tsx`, `Inbox.tsx`, `Reconciliation.tsx`, `Names.tsx`, `Einvoice.tsx`, `Ask.tsx`, `Results.tsx`, `KeyResults.tsx`, `Checker.tsx`, `How.tsx`: migrated page controls and panels; API-driven key results; formatted run details; document Tabs and quote highlighting; issues in an Alert; question Cards with argument chips and marked, linked numerical citations; RadioGroup checker; theme-aware SVG and the requested production follow-ups.
- `web/src/format.test.ts`, `components.test.tsx`, `web/tests/e2e/console.spec.ts`: formatter and component regressions plus every page, both viewports and themes, axe, overflow, console, skip link, quotes, VAT/emirate display, hosted guard, checker persistence checks, key results, absence of visible snake case, and open filters under the production CSP.
- `web/playwright.config.ts`, `web/tests/e2e_server.py`, `e2e_teardown.ts`: four browser projects and a fresh offline database; configurable default test port 5081; teardown targets the exact fixture PID because process-tree termination is restricted on this Windows host.
- `web/tsconfig.app.json`, `vite.config.ts`: retain the path alias without deprecated TypeScript `baseUrl`, and use `import.meta.dirname`.
- `backroom/m5_gate.py`: verify built stylesheet files exist and the app shell contains no inline styles under the existing CSP. `backroom/m3_gate.py`: put the cumulative gate's scratch databases under `.local/codex-m3-*`.
- `tests/test_ask.py`: correct a stale expectation for the existing food-cost answer key: cost and percentage, with sales asserted separately. Ruff also normalized the file's trailing test formatting. No Ask implementation changed.

The API routes, client contract and types were read and retained. Test databases are isolated under `.local/codex-*`; the normal application database was not accessed by this work. Existing cumulative gate scratch databases from the initial run used the old temporary path and were automatically removed; the gate now uses the requested prefix.

## Implementation notes and limits

The installed Radix Select emits inline style tags when opened. This failed the existing production CSP and hid still-focusable content from accessibility tools. The select adapter therefore composes the installed shadcn Button and Collapsible primitives, with selection, focus return, arrows, Home/End, typeahead, Escape, Tab and outside-click behavior. The CSP remains unchanged. Open-filter browser tests assert no style tags, no console errors and zero axe violations.

The SQL answer-key assertion was stale before this UI work; it now reflects the documented existing return value while preserving an independent sales assertion. Automated browser coverage is Chromium at 1440x900 and 390x844. The Postgres test is skipped because `DATABASE_URL_TEST` is not set; SQLite coverage passes. No other outstanding deviations or known failures remain.
